# Sample image provenance

The examples were found through a web search for the official scikit-image sample collection and loaded using `skimage.data` in scikit-image 0.24.0. Google Images is an index, not a source or license; this project uses the documented source collection instead of thumbnails.

Official documentation: https://scikit-image.org/docs/0.24.x/api/skimage.data.html

| Local image | Loader | Credit and licensing information |
|---|---|---|
| `coins.png` | `data.coins()` | Greek coins from Pompeii, Brooklyn Museum collection. Documentation states no known copyright restrictions. |
| `camera.png` | `data.camera()` | Modern replacement camera image, photograph by Lav Varshney. Documentation states CC0. The pre-0.18 camera image had different copyright issues and is not used here. |
| `page.png` | `data.page()` | Scanned-page sample distributed by scikit-image. The API identifies no separate photographer or image-specific license. The project has a general BSD-3-Clause notice; this is not a separate assertion that the page image is public domain. |

Upstream license: https://github.com/scikit-image/scikit-image/blob/v0.24.0/LICENSE.txt

A verbatim copy is included as `SCIKIT_IMAGE_LICENSE.txt`. Retain this notice when sharing the included sample material. The figures are generated from these samples by the accompanying notebook.
